# NewsDesk RSS Dashboard 1.0.6

The affected-PC comparison for issue #2 isolated a request-header compatibility
problem: both COM and native WinHTTP returned HTTP 403 with the app's headers,
and valid RSS with the original diagnostic's headers. Native WinHTTP succeeded
with automatic proxy discovery, so a proxy configuration change is unnecessary
for the demonstrated working request.

## Changes

- For native WinHTTP downloads of the original CISA All Advisories feed, use
  the shorter XML `Accept` header and omit `Accept-Encoding`, matching the
  successful work-PC request. The comparison changed these together and does
  not identify the individual CDN rule.
- Apply this profile only to feed requests for the tested CISA endpoint,
  selecting the profile again after each redirect. Other feeds and article
  pages retain their existing request headers and compression support.
- Preserve the WinHTTP -> .NET -> Python automatic order, conditional GETs,
  download/decompression limits, deadlines, proxy discovery and TLS checks.
  The successful request uses the same honest NewsDesk User-Agent.
- Add a regression server that refuses the old profile and accepts the
  CISA-compatible request, including a second conditional request/HTTP 304.
  Cover redirect transitions and isolation from unrelated sites/article pages.

## Update

Close NewsDesk, extract `NewsDesk-1.0.6.zip`, and run **Install NewsDesk**. Existing
subscriptions, reading history and settings use the separate user-data folder.
Select **Settings > Connection > Automatic** or **Windows (WinHTTP)**.

On the affected PC, add/refresh the original CISA URL and refresh it again.
Issue [#2](https://github.com/StevenMcGann/NewsDesk-RSS-Dashboard/issues/2) remains
open for confirmation in the integrated release. The request profile is verified
on that PC; a development-PC test alone does not establish that the installed
release works there.

See [the comparison results and investigation](../CISA-FEED.md).

## Validation

The portable build rechecked its Python download hash and Python Software
Foundation executable signature. On bundled Python 3.14.8, 113 tests ran:
111 passed and two optional external-network tests were skipped.

The packaged runtime subscribed to the live CISA feed through Automatic/native
WinHTTP, stored 30 articles, and refreshed again with no errors. Both requests
used the verified CISA header profile; neither fallback was called. ZIP CRC
checks passed and packaged source bytes matched the reviewed files.

CI links and the archive SHA-256 accompany the published assets. No database
migration is required. The 1.0.5 release remains available as a rollback package.
