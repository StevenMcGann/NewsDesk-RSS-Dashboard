# NewsDesk RSS Dashboard 1.0.7

NewsDesk could stop after a minimized or background browser window stopped
sending heartbeats, including while Windows was locked. The watchdog treated
three minutes of timer silence as proof that every window had closed.

## Changes

- Keep registered windows alive when browser timers pause. Heartbeat silence
  no longer stops the app.
- Track close notifications separately for each document. Closing one window
  cannot stop another paused window. Preserve the 25-second grace after the
  last registered window closes and the 120-second first-window startup grace.
- Handle reloads, back/forward-cache restoration, duplicate closes and late
  heartbeats without incorrectly reviving or expiring a window.
- Add **Settings > Help > Quit NewsDesk** to stop the app explicitly for every
  window, including when a browser crash or missing close beacon leaves a
  stale registration. Quit also works in `--stay` mode.
- Log the shutdown reason and preserve launch-token and Host/Origin checks on
  the lifecycle endpoints.

The reporter confirmed that CISA's feed now loads on the work PC in 1.0.6;
issue #2 is closed. This release retains that downloader fix.

## Update and check

Close NewsDesk, extract `NewsDesk-1.0.7.zip`, and run **Install NewsDesk**.
Subscriptions, reading history and settings stay in the separate user-data
folder. If an older background process remains, reopen the old app and close
its windows before installing; wait about 30 seconds for it to stop.

Leave the updated app minimized/in the background and lock Windows for longer
than three minutes. After unlocking, verify that the existing window still
works. Check two-window close behavior and **Settings > Help > Quit NewsDesk**.
Issue [#4](https://github.com/StevenMcGann/NewsDesk-RSS-Dashboard/issues/4) remains
open for affected-PC confirmation.

See [the investigation](../WINDOW-LIFETIME.md).

## Validation

The portable build rechecked the Python download hash and Python Software
Foundation executable signature. On bundled Python 3.14.8, 125 tests ran:
123 passed and two optional external-network tests were skipped. The new tests
cover long timer gaps, multiple windows, reload/close races, startup cleanup,
explicit Quit, `--stay`, invalid document IDs and lifecycle authentication.

ZIP CRC and packaged-source checks passed. Browser reproduction results, CI
links and archive SHA-256 accompany the published assets. No database migration
or additional dependency is required.
