# NewsDesk 1.1.0 — in-app updates and release notes

Install this version manually once to enable in-app installation of future releases.

- **Update** now opens release notes inside NewsDesk, with version and download size,
  **View on GitHub**, and **Download manually**.
- **Update and restart** downloads and verifies the release while you read. You can
  cancel before installation starts. Daily checks remain notification-only.
- Installed and writable local portable copies update in place, preserving feeds,
  reading history, settings, connection choices, shortcuts and installation mode.
- Open windows reconnect after a brief restart and restore their view where available,
  including windows paused in the background. Failed startup restores the previous
  application and data snapshot.
- Shared/network folders, read-only copies and source checkouts retain manual updates.

No new dependencies, administrator permission or permanent updater service are needed.

**Release status:** candidate; publishing requires successful Windows CI, CodeQL,
portable build and attended validation on both PCs. See [UPDATING.md](../UPDATING.md).
