# NewsDesk 1.1.5 — in-app update fixes for managed PCs

NewsDesk 1.1.5 fixes in-app updates that failed on some work and domain PCs
([issue #10](https://github.com/StevenMcGann/NewsDesk-RSS-Dashboard/issues/10)).

## Changes

- Fixed updates that stopped with "The update could not be prepared". During an
  update, NewsDesk and its update helper share a small status file. Windows refuses
  to replace that file while another program has it open, and on PCs with security
  software the two could collide. Saving the file now retries, and the helper no
  longer keeps it open while NewsDesk hands over the update.
- Fixed updates that installed but then reopened the previous version. The final
  step that confirms an update now retries when the status file is briefly in use,
  instead of undoing the update.
- Replacing the application folder now retries for up to 30 seconds while Windows
  reports it in use, for example while security software scans newly written files.
- PowerShell downloads and Edge no longer start inside the application folder, so
  they can't keep it in use during an update.
- Fixed a false "The update did not start" message after installing manually over
  a failed update. An update result now appears only on the version it applies to,
  and only once instead of in every new window.

## Updating from 1.1.0–1.1.4

The update helper comes from the new release, so most of these fixes apply while
you update to 1.1.5. The first step still runs in your current version, so on some
PCs it can stop with "Your current copy is unchanged". If that happens, choose
**Update and restart** again, or download `NewsDesk-1.1.5.zip` and run
**Install NewsDesk**.

## Validation

- All 175 unit tests passed on Windows with Python 3.12 and 3.14; two live-network
  tests were skipped. New tests reproduce the "Access is denied" failure on Windows
  and cover the retries, the update handoff and the update result messages.
- CodeQL and the packaged updater acceptance test (portable, installed and
  forced-rollback updates) passed.

## Installation

Use the in-app **Update** action from NewsDesk 1.1.0 or later, or download
`NewsDesk-1.1.5.zip`. The matching `.zip.sha256` file is attached for verification
and the updater. The release keeps Python 3.14.10. See [UPDATING.md](../UPDATING.md)
for verification and recovery.
