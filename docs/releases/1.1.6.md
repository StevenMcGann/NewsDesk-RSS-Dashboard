# NewsDesk 1.1.6 — easier quitting and reliable dependency checks

NewsDesk 1.1.6 adds an easy-to-find Quit button and fixes incomplete automated
dependency checks ([#16](https://github.com/StevenMcGann/NewsDesk-RSS-Dashboard/issues/16),
[#15](https://github.com/StevenMcGann/NewsDesk-RSS-Dashboard/issues/15)).

## Changes

- Added a power button beside Settings to **Quit NewsDesk**. When the sidebar is
  hidden, the button appears at the top right. It uses the same confirmation as
  Settings and stops NewsDesk and background checks for all open windows. Your
  feeds, settings and reading history are kept.
- Kept the Quit button accessible in narrow sidebars and refreshed the header
  controls immediately when showing or hiding the sidebar.
- Fixed automated dependency checks that failed when GitHub's unauthenticated
  rate limit was reached. GitHub API requests now authenticate without sending
  credentials to other services or following API redirects.
- Dependency checks now retain findings when another component or advisory cannot
  be checked. Incomplete coverage continues to report a failure and keeps the
  tracking issue open.
- Documented the review of Python advisory CVE-2026-124249: NewsDesk does not use
  the shared Python cookie jar required by this issue. Other advisory checks
  remain active. Bundled dependency versions and the normal 14-day adoption policy
  are unchanged.

## Installation

Use **Update** in NewsDesk 1.1.0 or later, or download `NewsDesk-1.1.6.zip` and run
**Install NewsDesk**. The matching `.zip.sha256` file is required for verification
and in-app updates. This release keeps Python 3.14.10. See [UPDATING.md](../UPDATING.md)
for verification and recovery.
