# NewsDesk 1.1.7 — better support for input methods

## Changes

- Pressing Enter to confirm text in an input method editor (IME) now leaves the
  dialog open so you can finish typing. Press Enter again to save or add the item.
  This applies to feed, folder, and tag fields that submit on Enter. Thanks to
  [Golden007-prog](https://github.com/Golden007-prog) for the fix.
  [PR #20](https://github.com/StevenMcGann/NewsDesk-RSS-Dashboard/pull/20)
- Updated Turndown to 7.2.5, which improves how Markdown export assembles output
  from article HTML.
  [PR #23](https://github.com/StevenMcGann/NewsDesk-RSS-Dashboard/pull/23)
- Updated the Setup Python and CodeQL actions used by the repository's automated
  checks.
  [PR #14](https://github.com/StevenMcGann/NewsDesk-RSS-Dashboard/pull/14)

## Installation

Use **Update** in NewsDesk 1.1.0 or later, or download `NewsDesk-1.1.7.zip` and run
**Install NewsDesk**. The matching `.zip.sha256` file is required for in-app
updates and can be used to verify a manual download. See the
[update and recovery guide](https://github.com/StevenMcGann/NewsDesk-RSS-Dashboard/blob/v1.1.7/docs/UPDATING.md).
